# Standard Work Sheet / SOP Template

Use one sheet per workstation task. Keep it to one page, write it with the operators who do the job, and review it whenever the process, equipment, product or a food-safety control changes. Each sheet is held in the OEIS document register (data entity DE-10) with a version number, owner and review date.
