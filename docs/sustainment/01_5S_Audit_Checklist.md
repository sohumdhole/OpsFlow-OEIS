# 5S Audit Checklist: Production Area

**Purpose.** A short, repeatable audit that a team leader can complete in 15 minutes at the start of a shift. Scores feed the OEIS `fact_5s_audit` table (see `docs/OEIS_Requirements.md`, data entity DE-09) so trends are visible on the daily board.

**Scoring.** Each item scores 0 (not in place), 1 (partly in place) or 2 (fully in place). Area score = total / maximum x 100. Any item scored 0 that touches food safety (marked FS) raises an action the same shift.
